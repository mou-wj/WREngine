# 优化点 - 2026-11-20

## SC-OPT-09 Radiosity 的采样质量与每帧更新预算

- 状态为固定采样和整图迭代已实现，质量与性能优化待验证。
- 每张 Card 使用 8×8 个间接光照单元，每个单元固定追踪 8 条射线。每轮更新整张图集和全部射线，自动执行上限为 32 轮。当前 Delta 视图提供逐单元变化，可用于观察收敛。 [算法说明](../../key_implemetion/algorithm/18-surface-cache-radiosity.md)
- 粗单元难以区分薄几何、窄缝和急剧材质变化。大场景的射线工作量随 Card 数增长，固定迭代上限可能提前停止高反射场景的传播。
- 先记录有效 Card 覆盖率、不同场景的轮间误差和 GPU 分阶段时间，再评估局部提高采样密度、基于误差结束迭代、按预算更新活跃 Card。稳定固定场景时保持可复现，避免更新顺序破坏跨轮隔离。射线候选遍历的优化沿用 [SC-OPT-04](优化点-2026-11-17.md#sc-opt-04加速对象级追踪card-查找和元数据上传)。
- 验收使用相同相机与输入对比高采样参考，记录误差、峰值内存、收敛轮数、分阶段 GPU 耗时，以及场景变化后是否及时失效。
