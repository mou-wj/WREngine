# 优化点 2026-11-22

## VOL-OPT-01 Froxel 重建与成本

当前每个像素执行最多 32 次积分，XY 方向使用最近 Tile。密度边缘、局部介质和细光束可能暴露 Tile 台阶。深度、相机和介质变化的时域累积尚未实现。先用同一测试场景记录分辨率和层数变化时的 GPU 耗时、峰值内存及画面差异，再评估边缘感知重建、历史重投影、受限抖动或稀疏调度。验收覆盖相机运动、动态光源和局部介质边缘。 [资源与积分](../../key_implemetion/algorithm/23-volume-rendering.md#图资源与边界)

## VOL-OPT-02 局部间接光与透明介质合成

当前体积环境光取全场景天空的六轴粗 Mip 平均。它对室内阴影、探针变化和颜色反弹没有空间区分。后续在接口稳定后对照当地入射 Radiance 的缓存质量，选择每个体素查询一次或分区采样。验收需要同一场景内的遮蔽房间和外部天空具有合理差别。

现有延迟合成以不透明 SceneDepth 为唯一终点。等透明渲染提供片元深度后，可评估在透明片元的深度位置求取累计散射和透射，用多层透明与不透明交叠作为验收用例。 [已接入的合成接口](../../key_implemetion/algorithm/23-volume-rendering.md#天空环境与合成位置)

## VOL-OPT-03 远距离密度采样和纹理容量

现有噪声与纹理均在 Froxel 中心采样，纹理固定读 Mip 0。体素覆盖范围超过密度细节尺度时可能出现欠采样。与重建优化一起评估按 Froxel 尺寸选择 Mip 或削弱高频噪声。每个视图最多绑定八张不同密度纹理。确有容量需求时再评估纹理组织方式，并以三个后端在相同输入下保持密度和透射一致为验收条件。 [密度实现](../../key_implemetion/algorithm/23-volume-rendering.md#非均匀密度)
