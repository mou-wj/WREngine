# 优化点

## 历史全局 Shader 的编译与启用边界

状态为待实现与验证。独立 SSR 和 HZB 的注册类型仍指向缺失的 Shader 源文件。旧 GlobalDiffuseLightMap 的计算 Shader 将运行时体素类型和生成的 Shader 类型混用，重复声明 irradiance 结构，并使用 GLSL 的 fract 代替 HLSL frac。三者独立于当前已通过的材质测试。后续按实际调用方补全算法、校对元数据和有效的缓冲布局后，用独立输入验证输出，同时检查全局启动日志。 [SSR 和 HZB 实现边界](../../key_implemetion/algorithm/07-screen-space-and-antialiasing.md#先区分是否接入) · [旧漫反射 Shader](../../../shaders/GI/GlobalDiffuseLightMapInitCS.sf)

## 局部灯光的遮罩阴影更新

状态为待改进。点光与聚光阴影更新目前由灯光代理的 bUpdateCastShadow 控制。测试切换遮罩覆盖率时显式触发灯光更新。材质值、实例覆盖或遮罩贴图变化应能有针对性地使有关灯光阴影失效，避免静态灯光继续使用旧轮廓。验收采用相同灯光与网格，在运行时改变阈值和纹理，对照灯光保持不动时的遮挡变化与重绘数量。 [阴影调度](../../../src/Framework/Renderer/Private/SceneRenderer.cpp)

## DirectX12 清除值优化

状态为待测量。Debug 的透明回归中，ID3D12CommandList::ClearRenderTargetView 报 820，实际清除值与创建时的优化清除值不同，像素检查正常。可按常用临时目标的清除值评估是否值得扩展优化清除值传递，验收基于有效 GPU 测量及相同清除数据，保留现有 RenderGraph 依赖。 [原生纹理创建](../../../src/Framework/RHIDirectX12/Private/DirectX12Resource.cpp)
