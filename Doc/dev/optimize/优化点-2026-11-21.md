# 优化点 - 2026-11-21

## RC-OPT-01 细薄遮挡与层级切换

- 状态为保守的方向距离和近场 SDF 筛选已实现，复杂场景待量化。
- 6×6 方向深度估计对薄墙、门缝、动态几何和细粗层边缘依然敏感。格点刷新也可能在相邻位置产生不同版本的间接光。
- 以带墙缝的双房间场景和移动相机对比全长追踪，记录最坏漏光、缓存命中率、细粗层边界变化和失效收敛帧数。按数据评估可见性矩、过渡融合和方向分辨率。 [查询算法](../../key_implemetion/algorithm/19-world-radiance-cache.md#查询与遮挡)

## RC-OPT-02 远场候选开销与按需更新

- 状态为固定预算和跨帧槽复用已实现，整帧收益待测量。
- 开启缓存后每条屏幕射线仍检查近场，另外支付方向查表与 64 字节临时存储。场景较小时，全长追踪的粗筛选也可能非常便宜。
- 在同分辨率、轨迹与场景下对比两种模式的 SDF 步数、Lookup 时间、刷新成本、整帧时间和显存峰值。然后评估把范围信息压缩成独立标记、依据使用频率刷新以及无效格点的更新退避。 [资源与预算](../../key_implemetion/performance/13-screen-probe-gather.md#世界探针缓存)

## GI-FILTER-OPT-01 动态表面与历史失效粒度

- 状态为相机矩阵重投影和基于实例、材质及灯光快照的全局失效已实现，局部失效待实现。
- GIViewer GBuffer 缺少物体速度和稳定表面标识。移动实例会清除全图历史，近共面薄层也可能通过几何阈值。原地编辑 RenderData 或 SDF 可能需要显式重建。 [历史失效条件](../../key_implemetion/performance/13-screen-probe-gather.md#屏幕历史与失效)
- 结合后续实际可用的 Motion Vector、表面标识和缓存修订信息评估按像素拒绝。验收包含移动遮挡物、共面不同材质、多室薄墙和切换灯光时的漏光、拖影与恢复帧数。

## GI-FILTER-OPT-02 历史带宽与探针覆盖

- 状态为屏幕域时空滤波已验证，实际 GPU 成本和复杂场景效果待测量。
- 1080p 两组 RGBA32F 屏幕历史的逻辑占用为 126.56 MiB。固定 Tile 在轮廓、接触面和薄物体处仍可能缺少相容 Probe。`out/pro2` 的单球只能检验模式显示与基本交互，不能代表彩色反弹场景的质量。 [滤波实现](../../key_implemetion/algorithm/20-gi-temporal-spatial-filter.md)
- 用固定相机轨迹对比 Raw、Temporal、Spatial 三种输出，记录帧间差异、轮廓泄漏、显存峰值和 Pass 时间。根据测量评估历史颜色/法线的精度压缩及高几何变化区域的探针补样；方向性探针滤波在必要性有量化证据后再评估。

## GI-REFL-OPT-01 粗糙反射质量与离屏着色

- 状态为混合路径可运行，逐像素粗糙反射质量及完整离屏镜面着色待改进。当前使用一个 VNDF 方向近似预滤波辐射，粗糙材质会有采样噪声，屏幕步进可能跳过亚像素物体。近相机位置计算视线，正交预览若未来引入需改用恒定射线方向。
- Vulkan 硬件路径已使用三角形法线、材质常量及场景空间阴影在命中点重新计算直接 PBR。SDF 继续复用 Card 的漫反射出射光与环境镜面。硬件纹理材质仍依赖 Card，覆盖缺失时会回退。屏幕命中的底色来自当前相机视角，近距反射仍使用几何偏移和距离阈值。 [命中点着色](../../key_implemetion/algorithm/21-hybrid-reflections.md#硬件命中与着色)
- 用平面镜、粗糙度阶梯和一明一暗的屏幕外物体衡量命中率、画面噪声和方向性误差。根据数据评估层级深度追踪、粗糙反射滤波与命中面可见性一致的直接 BRDF。 [算法说明](../../key_implemetion/algorithm/21-hybrid-reflections.md)

## GI-REFL-OPT-02 反射工作量与临时显存

- 状态为全分辨率逐像素缓冲已实现，显存峰值和时延待测量。屏幕可靠命中跳过后续几何追踪，查询和结果记录仍按全屏创建。1080p 中间数据逻辑总量在 SDF 下约 379.7 MiB，在硬件模式约 443.0 MiB。
- 测量分辨率、粗糙度和场景实例数变化时的 GPU 时间与峰值。用相同输入比较待追踪像素压缩、粗糙度自适应分辨率，以及带近场可见性校验的远场缓存早退。验收覆盖屏幕边界过渡和 SDF 遮挡一致性。 [反射资源](../../key_implemetion/performance/13-screen-probe-gather.md#反射图与资源)

## GI-HW-OPT-01 实例更新与命中材质

- 已有 Vulkan 静态三角形 BLAS/TLAS 和 Screen Probe、Reflections 接入。变换或材质修改会重建 TLAS 与元数据，BLAS 复用按 RenderData 身份判断。对不变的几何增加版本检查，对变换更新按需评估原位 refit。验收比较平移、旋转、非均匀缩放和实例增删时的命中一致性、上传量与更新时间。 [硬件资源](../../key_implemetion/performance/07-ray-tracing-as-and-sbt.md#giviewer-场景快照与-rdg)
- 尚未实现命中 UV 材质取样、Masked/动态变形和双面材质语义。若扩展，先明确 Shader 参数与命中几何记录的对应关系，再以细窄遮挡、纹理和高镜面模型对照。当前 Radiosity 与世界探针独立走 SDF，是否扩大硬件覆盖由时间与画质测量决定。
- 单球的 Trace Source 中 SDF 命中明显多于硬件。现有屏幕探针只沿法线偏移 0.03 世界单位，SDF 的体素容差会影响近面判定。后续读回首个命中实例与距离，确认近面自交比例，再考虑给探针补发射面标识和针对该实例的最小步进距离。验收用孤立凸体及相邻薄墙同时检查自交与真实近距遮挡。 [探针放置](../../../shaders/GI/ScreenProbePlacement.sf) · [SDF 查询](../../../shaders/GI/SurfaceCacheQuery.sf)
