# 优化点 - 2026-11-21

## RC-OPT-01 细薄遮挡与层级切换

- 状态为保守的方向距离和近场 SDF 筛选已实现，复杂场景待量化。
- 6×6 方向深度估计对薄墙、门缝、动态几何和细粗层边缘依然敏感。格点刷新也可能在相邻位置产生不同版本的间接光。
- 以带墙缝的双房间场景和移动相机对比全长追踪，记录最坏漏光、缓存命中率、细粗层边界变化和失效收敛帧数。按数据评估可见性矩、过渡融合和方向分辨率。 [查询算法](../../key_implemetion/algorithm/19-world-radiance-cache.md#查询与遮挡)

## RC-OPT-02 远场候选开销与按需更新

- 状态为固定预算和跨帧槽复用已实现，整帧收益待测量。
- 开启缓存后每条屏幕射线仍检查近场，另外支付方向查表与 64 字节临时存储。场景较小时，全长追踪的粗筛选也可能非常便宜。
- 在同分辨率、轨迹与场景下对比两种模式的 SDF 步数、Lookup 时间、刷新成本、整帧时间和显存峰值。然后评估把范围信息压缩成独立标记、依据使用频率刷新以及无效格点的更新退避。 [资源与预算](../../key_implemetion/performance/13-screen-probe-gather.md#世界探针缓存)

## GI-FILTER-OPT-01 动态表面与历史失效粒度

- 状态为相机矩阵重投影和基于实例、材质及灯光快照的全局失效已实现，局部失效待实现。
- GIViewer GBuffer 缺少物体速度和稳定表面标识。移动实例会清除全图历史，近共面薄层也可能通过几何阈值。原地编辑 RenderData 或 SDF 可能需要显式重建。 [历史失效条件](../../key_implemetion/performance/13-screen-probe-gather.md#屏幕历史与失效)
- 结合后续实际可用的 Motion Vector、表面标识和缓存修订信息评估按像素拒绝。验收包含移动遮挡物、共面不同材质、多室薄墙和切换灯光时的漏光、拖影与恢复帧数。

## GI-FILTER-OPT-02 历史带宽与探针覆盖

- 状态为屏幕域时空滤波已验证，实际 GPU 成本和复杂场景效果待测量。
- 1080p 两组 RGBA32F 屏幕历史的逻辑占用为 126.56 MiB。固定 Tile 在轮廓、接触面和薄物体处仍可能缺少相容 Probe。`out/pro2` 的单球只能检验模式显示与基本交互，不能代表彩色反弹场景的质量。 [滤波实现](../../key_implemetion/algorithm/20-gi-temporal-spatial-filter.md)
- 用固定相机轨迹对比 Raw、Temporal、Spatial 三种输出，记录帧间差异、轮廓泄漏、显存峰值和 Pass 时间。根据测量评估历史颜色/法线的精度压缩及高几何变化区域的探针补样；方向性探针滤波在必要性有量化证据后再评估。
