# 优化点 2026-11-28

## GI 降噪的动态几何历史

状态为待实现。当前相机矩阵能重投影静态表面，实例或材质快照变化触发 Viewer 全图重置。动态几何发生变化时，稳定区域也会损失历史。后续可由调用方传入物体运动向量及有效性，用移动、相交、显隐的模型检查历史拒绝范围与残影。

## GI 亮度矩的资源开销

状态为待测量。双槽 RGBA32F 亮度矩每信号像素占 32 字节，旧单轮路径也预留绑定。后续可比较方差开关对应的 Shader 变体、紧凑格式及半分辨率积分方式。验收应包含实际峰值显存、GPU 时间以及 HDR 强度变化下的一阶矩和二阶矩精度。 [当前资源布局](../../key_implemetion/performance/13-screen-probe-gather.md#屏幕历史与失效)

## 超分时域重建的运动与成本

状态为待扩展和测量。当前使用静态几何相机矩阵速度，场景变更按 View 历史整体失效。后续运动向量可复用 GI 降噪的动态表面信息。透明表面目前使用合成颜色差估计反应区域，固定设备深度阈值仍需用远景薄层和快速运动验证。对 Native、Quality 和 Performance 测量场景 Pass、超分 Pass 和总队列时间，以固定场景和窗口尺寸验证收益。 [超分实现](../../key_implemetion/algorithm/07-screen-space-and-antialiasing.md#时域超分辨率)

## 帧插值的呈现节拍与计时

状态为待接入。当前中点生成由计算 Pass 完成，窗口仍执行一次 Present。Vulkan 的默认 Mailbox 允许较新的提交替代未呈现图像，OpenGL 的交换缓冲在工作线程执行，目前没有用于插帧的显示节拍回报。需要按窗口选择可控的呈现策略，分别维护两次提交的资源访问 Fence，并为可证明顺序的后端验证真实帧 N、生成帧 N+0.5、真实帧 N+1。在能力不可用、错过时间窗或资源未就绪时继续呈现真实帧。

在接入后分别测量真实渲染、GPU 光流、插值、真实与生成 Present 次数、实际呈现间隔及等待下一真实帧的延迟。质量用移动物体、快速相机、透明或反射变化及大遮挡区域验证。 [当前预览实现](../../key_implemetion/algorithm/26-frame-interpolation.md)
