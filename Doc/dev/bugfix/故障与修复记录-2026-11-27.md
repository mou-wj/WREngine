# 故障与修复记录 - 2026-11-27

## 材质预览球的正面受光和拖动

材质属性页使用内置球、固定方向的平行光和独立的离屏场景。最初使用默认背面剔除时，预览球只剩外缘亮带。`BuildSphereData` 生成的三角形边叉积指向球内，而顶点法线指向球外。渲染器按三角形绕序剔除了靠近相机的外表面，随后用远端表面的法线计算光照。交换每个球面三角形的后两个索引后，正面绕序与法线一致。修正也适用于之后通过同一生成函数新建的内置球体。 [球体生成](../../../src/Framework/Engine/Private/Shape.cpp)

快速拖动时，ImGui 可能在同一帧收到最后一段位移和鼠标释放。仅检查 `IsItemActive()` 会漏掉这一段位移。预览同时处理 `IsItemDeactivated()` 帧，并跳过激活帧的位移，避免把按下前的移动计入环绕。左键或右键拖动改变相机视角，预览区域内的滚轮改变相机到球心的距离。 [预览输入](../../../src/Editor/MaterialEditor/Private/EditorMaterialPanel.cpp)

左栏先应用材质改动，右栏再读取当前材质实例。预览球直接引用共享材质，或者使用球自身的材质实例同步被覆盖的参数。面板仅在材质或相机变化时执行离屏渲染。预览场景和 512×512 颜色目标在首次显示时创建，关闭后等待该纹理 Tracker 记录的最后一次 GPU 访问完成，再移除组件并释放资源。更新材质之前也使用同一个完成点，保证上次绘制引用的材质资源仍然有效。

### 验证

- Visual Studio 2022 Debug 的 `Langcher` 与 `Tests` 目标构建成功。
- 在默认 Vulkan 编辑器中打开独立验证工程。共享材质的基础色由白变红时，颜色选择器打开期间预览已更新。通过 `Inspect mesh` 修改球体实例的基础色后，预览高光显红，点击 `Inherit parent` 后恢复白色。拖动使高光从球心附近移到右侧，滚轮缩小画面中的球体。关闭并重开预览后仍可使用，保持预览打开时也完成了编辑器退出流程。
- `Tests.exe -test=MaterialShadingModelTest -rhi=<后端>` 在 Vulkan、OpenGL 和 DirectX 12 均返回 0，输出 `MATERIAL_SHADING_MODEL_TEST_OK visibleModels=6`。该用例使用同一个球体生成入口，覆盖六种着色模型的渲染结果。编辑器的交互验证使用 Vulkan。
- 日志仍有历史全局 Shader 编译诊断，DirectX 12 专项还记录了清除值与资源创建值不同的 `D3D12 [820]` 提示。 [历史诊断](故障与修复记录-2026-11-21.md)
