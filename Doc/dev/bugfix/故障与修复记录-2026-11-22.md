# 故障与修复记录 2026-11-22

## Froxel 资源维度和 Shader 参数布局

第一版将 `RenderGraphTextureDesc` 指定为 3D，并在介质注入 Shader 中绑定 `RWTexture3D`。离屏测试复现了 `VUID-vkCmdDispatch-viewType-07752`，临时分配得到的视图是 2D，前景像素透射率仍为 1。Froxel 的逻辑三维坐标现在统一映射到二维切片图集，纹理、UAV、SRV 与 Shader 的维度一致。

OpenGL 的 SPIR-V 转换在体积常量块报告无法表达为 std140/std430/scalar。将网格配置、相机位置及深度范围打包到完整的四分量向量，去掉了交错的标量和向量布局。失败测试的进程仍持有隔离构建的 DLL，停止该测试并归档被占用的产物后重新链接。三后端均获得正常退出和与解析值吻合的读回。 [实现](../../../src/Framework/Renderer/Private/Volume/VolumeRendering.cpp) · [解析对照](../../../src/Tests/VolumeRenderTest.cpp)
