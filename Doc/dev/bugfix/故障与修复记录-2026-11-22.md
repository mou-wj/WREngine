# 故障与修复记录 2026-11-22

## Froxel 资源维度和 Shader 参数布局

第一版将 `RenderGraphTextureDesc` 指定为 3D，并在介质注入 Shader 中绑定 `RWTexture3D`。离屏测试复现了 `VUID-vkCmdDispatch-viewType-07752`，临时分配得到的视图是 2D，前景像素透射率仍为 1。Froxel 的逻辑三维坐标现在统一映射到二维切片图集，纹理、UAV、SRV 与 Shader 的维度一致。

OpenGL 的 SPIR-V 转换在体积常量块报告无法表达为 std140/std430/scalar。将网格配置、相机位置及深度范围打包到完整的四分量向量，去掉了交错的标量和向量布局。失败测试的进程仍持有隔离构建的 DLL，停止该测试并归档被占用的产物后重新链接。三后端均获得正常退出和与解析值吻合的读回。 [实现](../../../src/Framework/Renderer/Private/Volume/VolumeRendering.cpp) · [解析对照](../../../src/Tests/VolumeRenderTest.cpp)

## 体积光源缓冲与聚光测试采样

直接绑定现有混合标量和向量的三类场景光源缓冲时，OpenGL 在 SPIR-V 转换中拒绝缓冲布局，Vulkan 测试曾在执行前序体积用例时退出。光源改从启用的场景代理提取，上传到 Volume 自己的四分量对齐结构化缓冲。Vulkan 的首次退出没有单独定位到驱动调用。后续聚光读回验证还发现原先选择的左侧 Tile 中心约偏离 22.5°，仍落在测试锥角内。改用所处 Tile 确实位于锥外的最右像素。三后端最终正常退出，平行光相函数以及点光、聚光范围读回均符合测试输入。 [光源和测试](../../../src/Tests/VolumeRenderTest.cpp)

## 阴影夹具的齐次坐标

阴影读回的首次测试出现完整平行光贡献 0.330751。夹具使用默认构造的全零矩阵，只填了前三行的若干元素，导致投影结果的 w 为 0，运行时正确地拒绝了该投影。夹具改为由单位阵构造，令 w 为 1；三个后端均读回已遮挡的三类光源，保持透射率不变。 [夹具](../../../src/Tests/VolumeRenderTest.cpp)

## 3D 密度 Shader 的预处理与描述符

三维噪声初次编译时，DXC 将参数名 `point` 识别为 HLSL 保留修饰词，报 `modifiers must appear before type`。改用 `latticePoint` 后通过该阶段。随后，统一参数布局会在无纹理的图中留下未赋值的数组元素，而参数绑定会逐项解引用。首次拆分布局时还遇到 `Include file not found: /Generated/ShaderParameters/VolumeTexturedMediumParameters.sf`，因为项目会先展开全部 `#include`，然后才处理条件宏。两个入口文件现在各引用自己生成的参数，公用同一份介质主体。带纹理的入口填满描述符数组，通过常量索引适配未开启动态采样数组索引的 Vulkan 设备。

首轮动画断言只看切片中心，该位置纹理通道约变化 0.0047，未达到 0.01，其他 Tile 仍有明显变化。复测保留变化门槛，改为比较整个切片，并分别检查均匀通道稳定和第二张纹理确实贡献密度。Vulkan、DirectX12、OpenGL 均读回纹理通道最大变化约 0.0759，并正常退出。 [采样](../../../shaders/volume/VolumeDensity.sf) · [读回用例](../../../src/Tests/VolumeRenderTest.cpp)

## OpenGL 时空重建的图像绑定上限

首次编译空间重建 Shader 时，OpenGL 报 `image binding must be less than GL_MAX_IMAGE_UNITS (8)`。DXC 根据资源声明的顺序自动分配绑定，公用积分参数中的 UBO 和 SRV 位于重建输出之前，使 writable image 落到第 8 个索引或更后。重建 Shader 现在先展开自身的输出声明，再展开公用积分参数。三个后端均通过重建、历史和既有体积读回，OpenGL 复测未再报告该绑定错误。 [重建 Shader](../../../shaders/volume/VolumeReconstruct.sf)

## Vulkan 体积基准的时间戳录制

首次用 Vulkan Context 录制 GPU 时间戳时，测试把 `GetRecordedCommandBuffer()` 返回的上一条已结束缓冲交给 `vkCmdResetQueryPool` 和 `vkCmdWriteTimestamp`，触发两项 `commandBuffer-recording` 校验并异常退出。当前测试用独立命令池预录前后两个标记，在同一物理队列包围体积图的提交，通过 Fence 等待后读回时间戳。960×540 和 1920×1080 的两组基准均重复正常退出。 [基准代码](../../../src/Tests/VolumeRenderTest.cpp)

## 体积预览闪动与布局跳变

预览默认同时推进密度动画和 Froxel 采样相位，因此静止相机也会改变样本位置和介质密度，局部体边界及阴影附近会发生跳变。原布局将折叠项放在预览上方，展开后剩余高度改变并触发颜色目标和时域历史重建。现在初始和预设采用固定采样，动画和抖动可分别手动开启。折叠项放入左侧独立滚动区。Debug 编译和 Vulkan 完整延迟渲染离屏测试通过。复验展开画质、局部介质和形状控件，右侧预览边界不变，主积分尺寸保持 317×308，两项动态采样默认关闭。 [预览布局与默认值](../../../src/Editor/VolumeViewer/Private/EditorVolumeViewer.cpp)

## 水面存储图像类型与天空盒深度

Vulkan 创建水面计算 Shader 模块时报告 `Duplicate non-aggregate type declarations`。同一计算 Shader 同时声明 `RWTexture2D<float4>` 颜色及 `RWTexture2D<float>` 深度，DXC 将它们展开为两个相同的 `OpTypeImage %float 2D 2 0 0 2 Unknown`。水面 Pass 统一两个输出的存储图像类型，并约定下游读取有效深度的 R 通道。三个后端的 `VolumeWaterTest` 正常退出，独立 Vulkan 用例复测无校验输出。 [资源声明](../../../src/Framework/Renderer/Private/Volume/WaterRender.cpp)

编辑器开启大气时，远平面天空盒的角部出现灰块。天空盒顶点设置 `z=w`，着色时如果插值得到紧邻 1 的较小浮点值，原先的 `depth >= 1` 判断就会走几何大气透视分支。大气和水面在远平面保留两个浮点间隔作为背景容差。水面将这些样本以 1 写给下游。`VolumeAtmosphereTest` 用紧邻 1 的深度对照天空清屏样本。 [天空盒投影](../../../shaders/tools/DrawSkyVS.sf) · [远平面判定](../../../shaders/volume/AtmosphereScattering.sf)

## Subsurface 材质验证

内置球体切线 W 为零，顶点工厂原先以该值乘副切线后归一化。普通 Lit 无法线贴图时直接读世界法线，因此 Subsurface 初次经 TBN 取法线时才暴露了零长度副切线。现在无贴图直接使用几何法线，实际存在法线纹理时才做 TBN 变换。顶点工厂按 W 的符号生成副切线，零使用正号，与虚拟几何恢复一致。单位球测试使用双面设置确保近侧参与光照。 [顶点工厂](../../../shaders/vertexfactory/LocalVertexFactory.sf) · [GBuffer 输出](../../../shaders/core/MaterialGBufferHelper.sf)

旧构建的 OpenGL 材质编译已存在 `Buffer block cannot be expressed as any of std430, std140, scalar`。反汇编显示光源记录的 Direction 或 Position 紧随 LightId 从偏移 20 开始，与 GLSL 向量对齐冲突。调整光源记录为相同的 16 字节分组，同时更新 CPU 上传。前向像素着色器先声明光源缓冲区，避免原先生成的 `binding` 超过设备的 16 个 SSBO 槽位。 [光源布局](../../../src/Framework/Renderer/Private/SceneShaderParameters.h) · [前向声明](../../../shaders/material/StaticMeshMaterialShaderPS.sf)

延迟 IBL 原地读写同一颜色 UAV，OpenGL 原生编译要求设备未提供的 `GL_EXT_shader_image_load_formatted`。IBL 现以 SRV 读取直接光照并写入独立的现有延迟颜色附件。Vulkan 的 Subsurface 环境光像素读回复验通过。全局 Shader 加载仍有既存的 HZB、全局漫反射图及屏幕反射深度金字塔校验输出。 [延迟光照](../../../shaders/material/StaticMeshMaterialDefferedShadingCS.sf)
