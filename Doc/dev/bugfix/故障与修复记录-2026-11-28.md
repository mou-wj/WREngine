# 故障与修复记录 2026-11-28

## GI 时域降噪的 OpenGL 图像绑定

新增亮度矩资源后，`Tests -test=ScreenProbeFilterTest -rhi=opengl` 首次运行在 OpenGL 4.3 编译时域 Shader 时收到 `image binding must be less than GL_MAX_IMAGE_UNITS (8)`。自动分配的纹理和 UAV 绑定使用同一序列，新增的历史 SRV 把后续 UAV 推过设备的图像单元上限，计算程序未能链接，像素读回断言失败。失败运行未正常退出。

在 `ScreenProbeTemporalParameters` 和 `ScreenProbeSpatialParameters` 内优先声明 UAV，使自动绑定分配较低的图像槽位。Shader 通过反射按名称绑定，RDG 访问声明和计算流程沿用原设计。 [Pass 源码](../../../src/Framework/Renderer/Private/GI/ScreenProbeFilter.cpp)

修正后 VS Debug 的 Langcher 与 Tests 编译通过。Vulkan、DirectX 12、OpenGL 均运行 `ScreenProbeFilterTest` 并正常退出，交替噪声测试的时域 RMS 从 0.06 降到约 0.0006。读回还检查了相机平移、深度和法线拒绝、光照突变、方差估计、多轮深度边缘保留与间接光合成。

绑定调整前，在 Vulkan Launcher 中打开了包含球体、点光源和天空光的工程，检查了 GI Composite 和开启三轮空间滤波的画面，随后退出编辑器。启动日志仍包含已有的全局漫反射光图和 HZB Shader 编译错误。单球场景用于检查预览链路，降噪对边缘和噪声的影响由 GPU 读回用例覆盖。

## 时域超分的 Vulkan 存储图像类型

首次执行 Vulkan 超分读回测试时，Shader Module 校验报 `Duplicate non-aggregate type declarations`。一个 UAV 带 RGBA8 标注，另一个使用默认存储图像类型。检查输出 SPIR-V，两个存储图像类型最后都成了 `Unknown`，仍由不同 ID 声明。固定格式标注用于给 OpenGL 生成正确图像布局，Vulkan 改为沿用项目已有的无格式 UAV 写入。

VS Debug 构建通过后，Vulkan、OpenGL 与 DirectX 12 均通过 `SuperResolutionTest` 并正常退出。修正后的 Vulkan 测试日志没有该校验错误。Vulkan Launcher 的单球工程验证了开启前、Native 及 Performance 的实际画面，球体、背景、视口叠加与界面均显示。启动阶段仍有既有全局漫反射光图、SSR 深度金字塔和 HZB Shader 编译告警。

同一构建的 Vulkan `MaterialTransparencyTest` 和 `ScreenProbeFilterTest` 也通过回归检查。
