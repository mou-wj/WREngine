## Virtual Geometry 独立场景构图入口

新增 VirtualGeomtryRender.h/.cpp，将可见 StaticMeshProxy 筛选、现有实例 ID 查询、变换和材质快照整理，与 Visibility Raster、Material Resolve 的编排合并到 AddVirtualGeometryRender。入口使用调用方的 SceneDepth 与 GBuffer A/B/C，需要额外的 SceneView 提供相机和视口，不新增 Process 类或全局批次缓存。Raster 新重载直接使用传入的深度附件，原 width/height 接口继续保持自行创建深度的行为。使用条件见 [Renderer 使用约定](../../specification/renderer_spec.md)。RenderModule、传统延迟绘制及公共材质 Helper 均未修改。

## CPU 动态 LOD 选择与渲染接入

此前 Raster 通过 MipLevel 筛选生成层，不能作为完整场景 LOD：构建前沿可能保留上一轮未继续简化的 Cluster，而固定生成层会漏掉这部分区域。工程球体第 1 生成层为 466 面，构建该轮前沿为 492 面，已经体现该区别。此次新增独立 VirtualGeometryLODSelection.h/.cpp，使用原有 Group Child/Parent、GroupIndex、GeneratingGroupIndex、累计 Error 和历史 Bounds，从完整叶 Cut 按拓扑序执行满足像素预算的整组替换。Root 只表示终端集合，不做空替换；资源结构及 Build 实现均保持原样。

像素误差使用 ViewProjection×LocalToWorld 的齐次除法界定，分别计算横纵像素尺度，包含 Group 球的最近 W、偏轴投影和误差导致的 W 扰动。非均匀缩放、镜像和剪切直接进入矩阵；正交投影自然退化为线性尺度。眼点和近面穿越范围时保守细化。预算为零请求所有叶，默认值为 1 像素；它使用已有采样误差，不是严格表面像素上界。完整公式、Cut 证明、时间/空间成本和裂缝条件见 [核心算法](../../key_implemetion/algorithm/13-virtual-geometry-lod-selection.md)。

Raster 在构图时选择并保存一次 ClusterID 列表，Metadata 与命令录制共用此列表；Resolve 继续按实际 Cluster 的偏移和材质恢复属性，没有改动 Shader、GBuffer 或后端。AddVirtualGeometryRender 暴露可选像素预算，Viewer 默认启用 Dynamic LOD，并可编辑目标预算、查看实际混合层列表。原生成层筛选仅在显式诊断模式保留。主延迟 Renderer 未接入新的自动路径。
