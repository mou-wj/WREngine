# 故障与修复记录 - 2026-11-20

## GIViewer 标题栏关闭时访问已释放的预览纹理

### 现象与原因

在 `out/pro2` 打开 GIViewer 并显示预览后，点击 Viewer 标题栏的关闭按钮会导致编辑器退出。2026-11-19 的两次 Windows 应用错误均记录 `Langcher.exe` 在 `ImGuiSlate.dll` 内触发 `0xC0000005`，模块相对偏移为 `0x65F4D`。错误报告给出模块和偏移，以下时序来自本地源码核对。

1. ImGui 处理标题栏关闭按钮时会把 `p_open` 指向的 `m_bOpen` 设为 `false`。`ImGui::Begin` 的返回值独立于该标记，窗口内容在当前帧仍可能被处理。
2. 原 `EditorGIViewer::Draw` 只检查 `Begin` 的返回值，因此关闭帧仍能通过 `ImGui::Image` 把 `RenderTexture*` 编码为纹理 ID。`ImGui::End` 后，`GIViewerPreview::Reset` 又释放了该纹理。
3. `ImSlateRenderer` 在所有 Widget 绘制结束后调用 `ImGui::Render`。随后 `ImGuiRHIBackend::RenderDrawData` 解析纹理 ID 并读取纹理的访问状态。此时当前帧的绘制列表仍引用已释放的对象。预览 Reset 等待的 Fence 只覆盖已提交的访问，无法覆盖这条尚未录制到 RHI 的绘制命令。

### 修复与验证

`EditorGIViewer::Draw` 同时检查 `m_bOpen` 与 `ImGui::Begin` 的结果。关闭帧跳过预览绘制和纹理登记，仍调用 `ImGui::End`，随后按原有 Fence 释放路径清理资源。详见 [EditorGIViewer.cpp](../../../src/Editor/GIViewer/Private/EditorGIViewer.cpp)、[GIViewerPreview.cpp](../../../src/Editor/GIViewer/Private/GIViewerPreview.cpp) 和 [UI 纹理生命周期](../../key_implemetion/performance/08-ui-rendering-and-window-lifetime.md#采样纹理在哪里更新-fence)。

- Debug 构建通过。命令为 `cmake --build out/build/vscode-x64-Debug --target Editor Langcher --config Debug -- /m:8 /v:q /clp:ErrorsOnly`。
- 使用默认 Vulkan Editor 打开 `out/pro2`，验证了 Scene 模式下关闭、重开、再关闭。补测时构建 Surface Cache，确认 6 张 Mesh Card 和 Coverage 图集可见，再切换到 Screen Probes / Ray Directions，确认预览有输出。点击 Viewer 右上角关闭后，主窗口继续显示球体场景，进程仍响应，未新增崩溃转储。
- 回归范围为关闭 GIViewer 浮窗。编辑器主窗口在补测后保持开启。

## Surface Cache Radiosity 开发与验证

### 测试场景的 SDF 未命中

四色墙专项的首次读回中，红墙直接出射光 R 为 0.840338，白墙直接光为 0，但所有间接结果均为 0。单独发出从白墙朝红墙的 SDF 射线也返回未命中。专项手工构造墙体网格时填入了 LOD 顶点和索引，遗漏了 `StaticMeshRenderData::Bounds`。`BuildCPUData` 使用该网格的 Bounds 设置局部 SDF 体积。错误的体积导致该实例在追踪前被排除。为测试输入补充真实几何边界，并断言基准射线命中红墙内表面的 Instance 0、Card 4。 [四色墙测试](../../../src/Tests/SurfaceCacheRadiosityTest.cpp)

### 关闭探针多次反弹开关时访问异常

在 `Screen Probes / Indirect Diffuse` 中关闭 `Use radiosity in Screen Probes` 后，隔离版 Editor 发生 `0xC0000005`。原有 `SurfaceCacheDirectLightingTest` 也在相同偏移崩溃。转储把异常定位到 `RenderCore::RenderGraphTexture::GetRHITexture + 0x27`，调用点为 `RenderGraphBuilder::AnalyzePasses + 0x340`。扩充结构后的直接光照 `Register` 和更新路径只赋值了 `DirectRadiance`。RenderGraph 根据结构元数据登记读访问，解引用了未初始化的间接图集指针。修复将两种直接光照入口统一为值初始化。间接 SRV 绑定同一张直接图集，`RadiosityTileSize=0` 让 Shader 跳过间接采样。 [参数初始化](../../../src/Framework/Renderer/Private/GI/SurfaceCacheDirectLighting.cpp)

### 天空盒预览附件格式

`out/pro2` 的预览还出现 Vulkan `VUID-vkCmdDrawIndexed-renderPass-02684`。GIViewer 为可写调试输出传入 `R32G32B32A32_Float` 目标，而 `AddDrawSkyBoxPass` 创建 PSO 时固定使用 `R8G8B8A8_UNorm`。天空盒现从调用者传入的颜色和深度附件读取格式，以实际 RenderPass 参与管线缓存。 [天空盒 Pass](../../../src/Framework/Renderer/Private/DrawSkyPass.cpp)
