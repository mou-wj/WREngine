## RDG 非 Shader 访问回归参数元数据

之前为 Virtual Geometry 顶点、索引和测试读回，在 RenderGraphPass 上增加 AddBufferAccess/AddTextureAccess，使访问声明同时存在于参数结构和构图后的额外调用中。按项目既有参数驱动设计，现已移除这两个公共接口。EShaderParameterBaseType 增加 RDGTexture_Access/RDGBuffer_Access，ShaderParameterTypeInfo 和成员元数据增加 RHIResourceAccess，通过 RDG_TEXTURE_ACCESS、RDG_BUFFER_ACCESS 宏声明访问方式。Builder 解析参数时登记原有意向，后续依赖、状态转换和 Fence 处理沿用现有机制。

HLSL 生成与 Shader 绑定显式排除 Access 类型，避免访问声明错误地占用描述符或产生无类型 Shader 变量。Raster 的位置/索引声明已迁移到参数，两个虚拟几何测试的读回声明也已迁移，原测试输入、像素期望和提交过程保持一致。纹理宏目前声明 whole 子资源访问。详细调用方式见 [RDG 参数访问声明](../../key_implemetion/performance/03-rdg-execution-and-state.md#显式非-shader-访问与只读状态转换)。

本次回归暴露 DirectX12 上下文池的并发缺陷。原 AcquireCommandContext 在 RDG 多个录制任务中同时遍历、扩容 m_Contexts 并修改 bReusable，缺少同步。原生调试日志报告已释放堆块被修改和 c0000374，栈包含上下文 vector 扩容及 RenderGraphBuilder::ExecutaPasses 的录制任务。现让申请、归还、提交和完成遍历使用同一递归队列锁，允许 Release 内部调用 WaitValue 及完成回调沿既有调用链重入。WaitValue 只清理仍处于可复用状态的上下文，避免清理已重新借出录制的对象。原生 Fence 等待及访问记录机制沿用既有流程。早期失败与调试栈在 out/diagnostics/rdg-access-dx-debugger2.log，后续验证结果单独记录。

OpenGL 连续场景的退出 3 也已取得具体栈。复用的图形上下文缓存上一场景的顶点缓冲裸指针，独立网格资源销毁后，下一场景 SetGraphicPipelineState 先执行 ApplyVertexDescState，对旧指针做 dynamic_cast，触发运行库异常和 abort。修改为设置 PSO 时只标记顶点布局 dirty，沿原有 Draw/DrawIndexed 的逻辑，在本次 SetStreamSource 执行后应用布局。该修正保持队列、资源所有权和 Fence 约定。诊断在 out/diagnostics/rdg-access-gl-exceptions.log。

## Virtual Geometry Material Resolve 对接

新增 VirtualGeometryMaterialResolvePass，按 Visibility 中的 DrawID/PrimitiveID 读取 Cluster 局部索引、属性和实例快照，使用透视重心权重重建属性。材质参数及纹理采样沿用现有 MaterialShaderParameters/MaterialParametersHelper，Compute 通过解析 UV 梯度使用 SampleGrad。输出为原有 GBuffer A/B/C，随后调用既有 DeferredShadingCS。用户澄清范围后已移除此前尝试的额外自发光附件和专用合成 Shader，Lit 沿用当前 GBuffer 能力，Unlit 保留原有 BaseColor 与自发光相加规则。实现和限制见 [Material Resolve](../../key_implemetion/algorithm/12-virtual-geometry-material-resolve.md)。

本次遇到并处理了以下实际问题。

- HLSL 中 triangle 是保留字，局部索引变量改为 triangleOffset 后编译成功。
- 纹理边缘的验证参考最初使用连续渐变，忽略 LinearWrap 在首末 texel 间的混合。CPU 参考改为真实的循环双线性采样，采样接口和 Shader 输入保持一致。
- DirectX12 默认 Texture SRV 使用空原生描述，D32 资源会生成非法 D32_FLOAT SRV。默认描述改为明确的维度、Mip 和 Shader 可读格式，Utils 将深度格式转换为 R32_FLOAT 或 R24_UNORM_X8_TYPELESS。修复后 Depth 可用于 Resolve 的有效像素检查。
- OpenGL 将 Texture.Load 和材质采样组合为 GLSL sampler 时，多个图像误用相同绑定。组合 sampler 继承原图像绑定，真实 sampler 依据已有 CombinedBindings 反射绑定到对应纹理单元，dummy sampler 使用独立无效绑定标记。
- OpenGL UAV 视图在 Format 未指定时按默认 RGBA8 创建，与 GBufferB 的 RGBA16F 不兼容，法线附件读回为零并有 GL_INVALID_OPERATION。SRV/UAV 的 Unknown 格式统一继承源纹理格式，修复后法线及 PBR 通道读回正确。临时原生诊断回调已删除。
- 原 DeferredShadingCS 以尺寸整除 8 调度，非整倍数会遗漏边缘。调度改为向上取整，并在 Shader 中检查像素范围。

构图期间的实例变换和材质槽来自不可变快照，Metadata 增加 InstanceIndex。所有属性缓冲、Metadata、Visibility 与 Depth 声明 SRV，三个 GBuffer 声明 UAV，沿用原 RDG 资源访问与提交 Fence。独立 Resolve 使用每 Draw 一次全视口 Dispatch，后续性能优化需按实际开销评估。

Material Resolve 最终五场景读回在 Vulkan、DirectX12、OpenGL 分别退出 0，用时 2.59、2.24、2.75 秒，标准错误均为空。测试逐像素核对线性循环采样、两个实例的材质差异、Metadata 与资源映射、法线半浮点值、Roughness、Specular、AO 和 ShadingModelID。透视场景验证 UV 属性恢复，正交场景验证遮挡顺序。结果见忽略目录 out/diagnostics/virtual-geometry-resolve-final-verification.json 和同前缀后端日志。原 VirtualGeometryRasterTest 亦重新在三后端通过。
