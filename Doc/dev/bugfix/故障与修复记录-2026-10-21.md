# 故障与修复记录 - 2026-10-21

## 记录范围

本记录整理 RHI 光线追踪开发中已定位的故障、修复方式和验证依据；接口限制和后续改进统一记录在 [优化点](../optimize/优化点-2026-10-21.md) 中。后端职责和实现结构参见 [RHI 架构文档](../../architecture/rhi/rhi.md) 与 [OpenGLRHI 架构说明](../../architecture/rhi/rhiopengl.md)。

本次 Vulkan、D3D12 基础光追修复均已完成原始 30000 帧测试，自然退出 0，验证日志为空。OpenGL 按用户确认的范围，仅检测能力并明确报不支持，暂不实现软件光追。

## Vulkan：故障与修复

| 问题 | 原因与处理 |
| --- | --- |
| 着色器模块创建时报 RayQuery VUID | DXC 生成的 SPIR-V 声明 RayQueryKHR，但设备没有启用扩展及 feature。增加扩展、查询并启用 rayQuery。 |
| SBT 内容未初始化 | 原代码只分配固定的 4×64 字节，没有查询和复制 shader group handle。改为创建管线后查询 handle，按设备的 handle/base alignment 布局各表，空表使用零地址和零大小。 |
| TLAS 引用随机实例 | 构造了 CPU 实例数组却没有复制到 GPU 可见内存。上传完整实例数组，并保存 RHI 实例描述。 |
| BLAS/TLAS 构建和读取缺少同步 | RHI Buffer/BVH transition 原来被忽略。补充 memory barrier，access 枚举转换放在 VulkanRHIUtils。 |
| scratch 地址和复用风险 | 查询设备 scratch 对齐要求；保留录制中被替换的 scratch buffer，并为连续构建复用 scratch 增加屏障。 |
| TLAS update 的创建标志不一致 | 大小查询和实际构建均允许 update；BLAS 禁止对未声明 AllowUpdate 的资源执行 update。 |
| VulkanRHIApi 跨 DLL 的类布局不同 | DEBUG_INFO 是后端私有宏，却控制公开头中的成员。保持成员布局固定，避免测试中直接 new 时分配不足。 |
| 交换链等待阶段不覆盖光追 | 测试传入 ColorAttachmentOutput，但首次访问实际来自光追 UAV。后端对 binary acquire semaphore 使用 ALL_COMMANDS 等待，覆盖光追/计算/传输访问。 |
| 交换链 RHI 描述尺寸错误 | VkImage 使用实际客户区尺寸，RHI 描述却沿用请求的窗口外框尺寸。创建后用原生 extent 更新 Width/Height，本机实际为 496×473。 |
| 能力标记与实现不一致 | Vulkan 初始化成功后报告 EnableRayTracing=true，关闭后清除；D3D12 则查询选中适配器的 DXR tier。 |

## D3D12：实现过程中遇到的问题与修复

| 问题 | 排查证据与解决方法 |
| --- | --- |
| DXIL library 资源使用未解析的 register space | 反射后创建 root signature 报 nonzero space。增加 library 的 auto-binding-space；最终按 shader frequency 分配，root signature 按 shader 对象和原生 register space 绑定。 |
| 创建 state object 时原生访问异常 | 调试器定位到 CreateStateObject，记录了 D3D12 设备移除及调用栈。使用反射修饰名直接导出时复现；改用打包头里的入口名并为各 library 导出唯一别名后消失。未修改 HLSL 入口或关闭 debug layer。 |
| scratch 创建警告 1328 | 新版 D3D12 对普通 buffer 的创建状态按 COMMON 处理。scratch 创建为 COMMON，首次构建显式转到 UAV，后续复用使用 UAV barrier。 |
| 30000 帧后进程卡住 | 调用栈停在最后一个 UAV 析构中的 FreeDescriptor/mutex，设备此前已销毁。加 lifetime token 后，完整测试自然退出 0。卡住的旧验证进程曾被外部终止，不能算退出验证通过。 |
| 普通三角形回归时 RTV/PSO 格式不匹配 | 早期把整个交换链改为 RGBA8，导致测试原有 BGRA8 PSO 报 D3D12 错误 613。最终保留原生 BGRA8，只为 UAV 创建内部 RGBA8 图像并转换写回；未改测试 PSO，回归已恢复。 |

## OpenGL：避免未执行光追却报告成功

- 现象：光追资源/管线工厂返回 nullptr，上下文光追命令为空实现；测试可能跳过实际渲染后正常退出。
- 原因：OpenGL 后端未实现软件 BVH 与光追 shader 调度，但缺少一致的失败语义。
- 处理：保持 `EnableRayTracing=false`；创建 BLAS/TLAS、光追 shader/管线及绑定、构建、更新、TraceRays 接口统一抛出明确的不支持异常，错误函数集中在现有 OpenGLUtils。
- 验证：选择 OpenGL 执行光追测试时明确报错并退出 1。此结果验证了不支持路径，不代表 OpenGL 光追渲染成功。
