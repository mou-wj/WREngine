# GI Voxel Lighting

`VoxelLighting` 为 GIViewer 的 Screen Probe 提供低频方向性入射 Radiance。Surface Cache 保存表面的出射光，世界探针负责沿方向追踪并采集它，体素只对已有世界探针采样做重采样。Screen Probe Integration 继续负责接收面的材质反射，体素注入和读取都直接处理线性辐射。 [世界探针](19-world-radiance-cache.md) · [屏幕积分](17-screen-probe-gather.md)

## 世界坐标与六方向数据

使用世界探针的粗层 `LevelOrigin1` 和格距 `CellSize.Y`。当前网格为 `6³`，格点相隔 5 个世界单位。格点 `c` 位于 `c × 5`，在 3D 纹理中以正模环绕索引。相机移动时，重叠格点的世界坐标、物理地址和值都保持一致。每个格点有 `+X/−X/+Y/−Y/+Z/−Z` 六个方向，每个方向占两组深度分层中的两个 texel。 [格点寻址](../../../shaders/GI/VoxelLightingGrid.sf) · [资源布局](../performance/13-screen-probe-gather.md#体素光照缓存)

`VoxelLightingInject` 读取每个有效粗层节点的 `6×6` 八面体方向记录。将方向 `d` 按最大绝对分量与符号划入对应轴，边界平手时优先 X、Y、Z。八面体平面上到原点的垂直距离固定，投影到单位球面时立体角面积与到原点距离的三次方成反比。在该面上 `|p.x| + |p.y| + |p.z| = 1`，因此以 `(|d.x| + |d.y| + |d.z|)³` 近似每个八面体 texel 中心的立体角，并对每个方向的 RGB 求加权均值。 [注入 Shader](../../../shaders/GI/VoxelLightingInject.sf)

方向的第一组 texel 保存线性 RGB 和有符号最短距离，正值为几何命中，负值为天空，零表示当前方向不可用于光照。仅当该方向收集到的源样本全为几何或全为天空时才发布其光照。第二组 texel 保存最远有效距离以及净空距离，后者取已知样本的最短距离，遇到未判定样本则写零。几何与天空混合的方向可以为连接检查提供净空信息。

## 方向与空间查询

1. `LookupVoxelLighting` 以世界位置除以格距得到格点坐标，取小数部分计算 8 个角的三线性权重。基点和上边界都必须位于当前网格内。
2. 对每个角，根据单位查询方向各分量的符号选择对应三轴，使用 `d.x²`、`d.y²`、`d.z²` 为方向权重。主轴必须有效，同类方向权重至少为 0.85，重新归一化后得到该节点的方向性 RGB。天空必须覆盖射线剩余长度与节点偏移，几何最大命中距离必须落在剩余追踪范围内。几何扇区的远近跨度还须小于 `max(spacing, 0.35 × minDistance)`。
3. 用节点到查询点的位移方向选择相应的轴向净空。净空须覆盖实际偏移距离并留 `0.15 × spacing` 余量，否则剔除该点。有权角节点的原始权重至少保留 0.75，且结果只允许同属天空或几何的节点参与，再按有效权重归一化。
4. 屏幕射线从前 4 个世界单位之后查询。体素命中返回来源 3。体素被拒绝时尝试世界探针细层和粗层。无候选时按照完整射程追踪。有候选时继续走已有 SDF 或硬件路径验证近场，只有确认近场未命中才接受候选。遮挡或追踪未判定时由现有 Screen Probe Gather 处理。 [空间查询](../../../shaders/GI/VoxelLightingLookup.sf) · [筛选与回退](../../../shaders/GI/WorldRadianceRayLookup.sf) · [屏幕合并](../../../shaders/GI/ScreenProbeGather.sf)

同一查询每节点最多约 9 次 3D texel 读取，8 个节点最多约 72 次。World Cache 每级同样最多 8 节点，但方向查询可读取邻近的多组八面体样本。体素被拒绝时还需执行 World Cache，读取数和分支数都可能上升。净空来自有限方向的 SDF 样本，薄墙及亚格点遮挡仍可能漏检。混合扇区、高深度变化和网格边界会降低命中率。 [三后端读回](../../dev/bugfix/故障与修复记录-2026-11-21.md#gi-体素光照验证) · [待优化项](../../dev/optimize/优化点-2026-11-21.md#gi-voxel-opt-01-命中率与查询成本)
