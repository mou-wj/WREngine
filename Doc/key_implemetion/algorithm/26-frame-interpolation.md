# 双向光流与中间帧预览

## 输入和亮度金字塔

[FrameInterpolation](../../../src/Framework/Renderer/Private/PostProcess/FrameInterpolation.cpp) 采集相邻两张真实场景图。主视口有时域超分时采集重建后的颜色，否则采集原尺寸场景颜色。捕获发生在编辑器彩色叠加和 ImGui 合成前。真实帧槽的 RGB 保存线性颜色，alpha 保存零到一的设备深度。深度分辨率低于输出时，按原尺寸 UV 加上本帧渲染抖动取最近纹素。使用无抖动的视图投影和逆矩阵计算相机运动。

[FrameLuminance.sf](../../../shaders/tools/FrameLuminance.sf) 先将 RGB 转为 `log2(1 + dot(rgb, lumaWeights))`，然后分别对两帧做 2×2 盒式降采样。四层亮度以 RG 通道保存前后帧数据，最细层每轴为输出的一半，最粗层约为 1/16，奇数边界采样夹紧。

## 双向搜索

[FrameFlow.sf](../../../shaders/tools/FrameFlow.sf) 对每层像素各做两次搜索，分别用前帧和后帧作为搜索原点。候选来自粗一级向量乘 2 后周围的 5×5 窗口，以及零运动。错误函数为 3×3 块的平均绝对亮度差，另加轻微的长向量惩罚。记录最优向量与次优代价，最优与次优越接近或误差越大，置信度越低。光流纹理的 XY 保存本级像素位移，Z 保存置信度，W 保存匹配代价。最坏每层每像素评估两个方向各 26 个候选。边界夹紧、重复纹理和单色区域会削弱估计。

## 中点重建

[FrameInterpolate.sf](../../../shaders/tools/FrameInterpolate.sf) 先将光流除以最细层尺寸转换为 UV 位移。以反向光流回环的一致性和正反置信度评估图像运动。图像运动不足以信任时，使用相机投影对有深度的点计算静态几何位移。每个方向以输出 UV 减去半帧运动估计源坐标并再采样一次运动细化。两个 warp 深度差超过 0.002 且近处 warp 有足够支持时，抑制远处颜色。按有效置信度混合，两个方向均无支持时取当前真实帧像素。纯相机运动、遮挡边缘与图像光流有不同的有效范围。此版本没有物体运动向量，设备深度只用于近似遮挡判断。

## 资源与验证

Renderer 的 Scene 串行构图，包含两张输出尺寸 RGBA32F 真实帧纹理，每输出像素占 32 字节。亮度和光流纹理是 RDG 临时资源。每次采集只写一个缓存槽，光流读取前后两个真实帧，Resolve 写预览目标。生成结果留在显示纹理，真实帧缓存与超分历史读取的是生成前的颜色。对每个真实帧仍只进行一次逻辑更新和窗口渲染。切换目标、首次捕获、尺寸变化、相机切换或 3–250 毫秒以外的帧间隔返回真实画面。旧帧的最后访问 Fence 在缓存退休时等待，正常提交由 RDG 跟踪访问。

VS Debug 的 Vulkan、OpenGL 和 DirectX 12 像素读回中，输入平移 4 像素，预览结果对照理论平移 2 像素中点，RGB 单通道 MAE 约 0.0342。另检查首帧跳过、长间隔后失效和显式重置。现阶段预览替换既有单次窗口呈现的场景颜色。实际呈现 2×、GPU 各阶段计时和显示延迟尚未验证。 [GPU 测试](../../../src/Tests/FrameInterpolationTest.cpp)
