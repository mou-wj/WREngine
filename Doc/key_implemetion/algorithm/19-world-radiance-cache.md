# World Space Radiance Cache

世界探针存储沿世界方向查询的入射 Radiance。沿方向 `ω` 追踪命中时，样本值来自该命中点朝向探针的表面出射光，包括直接光照与可选的 Surface Cache Radiosity。远场查询返回该方向的样本，接收面的材质仍在 Screen Probe Integration 中计算。 [Screen Probe 积分](17-screen-probe-gather.md)

## 世界网格与方向采样

两级网格各含 `6³` 个节点，格距分别为 2、5 个世界单位。绝对格点坐标为 `c`，世界位置为 `c × spacing`。每级的有效范围从 `floor(camera / spacing) − 3` 开始，连续覆盖 6 个格点。槽索引逐轴取 `((c mod 6) + 6) mod 6` 后线性化。相机跨格只改变进入或离开区域的槽键，重叠格点的世界位置及纹理行均保持固定。 [实现入口](../../../src/Framework/Renderer/Private/GI/WorldRadianceCache.cpp)

每个节点用 6×6 八面体方向样本覆盖整个球面。编码先除以方向向量的 L1 范数，将负 Z 半球折叠到正方形边缘。解码计算 `z = 1 - |x| - |y|`，按相同折叠还原后归一化。射线使用每个方向像素的中心，方向查询做手动双线性插值，越过边缘时按折叠镜像定位邻点。方向数据用于查询和插值，屏幕探针仍使用自己的半球 PDF。 [方向映射](../../../shaders/GI/WorldRadianceOctahedral.sf)

世界探针每条射线的长度为 100 世界单位。命中有效材质且正对探针时，图集保存线性 `RGB` 和正的命中距离。确认未命中时保存环境光与负的最大追踪距离。无法判定的追踪、背面和无有效材质的命中写零距离，表示方向无效。 [缓存写入](../../../shaders/GI/WorldRadianceStore.sf)

## 查询与遮挡

屏幕探针从当前射线起点向前 4 个世界单位采样缓存。查找从细层开始，对查询坐标所在的单元做三线性插值。对每个有权重的节点，先用探针到查询位置的方向读取邻近方向样本，取最短的记录距离。若最短距离没有超出节点与查询点的距离及 `0.15 × spacing` 余量，剔除该节点。

随后沿原射线方向读取 Radiance。以最近方向样本的类型为基准，对同属天空或同属几何的有效四邻进行归一化插值，保留权重至少为 0.8。最近记录距离必须超过节点偏移与一个格距，远近距离跨度与射线剩余长度也受约束。可用节点的原始权重之和至少为 0.75，并且不能混合天空与几何结果。通过时归一化剩余权重，细层不可用时尝试粗层。缓存使用方向与深度样本估计遮挡，细墙、窄遮挡及粗糙的 SDF 仍可能漏检。 [空间查询](../../../shaders/GI/WorldRadianceLookup.sf)

缓存候选有效时，原 SDF Pass 继续追踪完整的前 4 个单位，有近场命中时优先使用实际查询。短射线确认未命中时才使用远场候选。候选无效时保留原射线长度。近场步数耗尽时屏幕 Gather 不用候选填补。命中后按正常流程读取或组合 Radiance。 [筛选](../../../shaders/GI/WorldRadianceRayLookup.sf) · [屏幕合并](../../../shaders/GI/ScreenProbeGather.sf)

每条屏幕射线每级最多检查 8 个格点，最多进行两组方向四邻访问。粗方向和相机覆盖边界会影响命中率。该路径能减少一部分远场遍历与步进，整帧耗时还取决于查表成本、缓存刷新预算以及场景复杂度。 [生命周期与代价](../performance/13-screen-probe-gather.md#世界探针缓存)

三后端使用两面墙场景读回方向图集和实际 Screen Probe 结果，覆盖颜色反弹、细层网格移动、近墙遮挡和灯光失效。另在隔离版 Launcher 验证图集和命中视图。 [验证结果](../../dev/bugfix/故障与修复记录-2026-11-21.md#世界探针缓存验证)
